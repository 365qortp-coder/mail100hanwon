## 1. `seocheck.py` — 전체 검사 (제일 많이 쓴다)

```bash
python C:\claude\mail100hanwon\_도구\seocheck.py C:\claude\내사이트
```

| 붙이는 말 | 뜻 |
|---|---|
| `--type a` | 여러 장짜리 홈페이지 (기본값) |
| `--type b` | 랜딩 1장 — **링크·글자수 기준이 완화된다** |
| `--pages a.html,b.html` | 일부만 |
| `--all` | 항목당 12개만 보여주는 걸 전체로 |
| `--json 결과.json` | 결과 저장 (전후 비교용) |
| `--no-schema` | 스키마 검사는 건너뛰기 |

**끝나면 `schema-check.py` 가 자동으로 이어서 돈다.** 따로 칠 필요 없다.

보는 것: 제목·설명·대표주소(canonical)·모바일 설정·언어·문자셋·OG·H1·제목 계층·설명표 유무·이미지 대체글·깨진 링크·내부 링크·글자수 + 폴더 전체(robots.txt·sitemap.xml·**네이버 봇 허용**·AI 봇 차단 여부·소유확인 표시)

## 2. `schema-check.py` — 기계용 설명표(JSON-LD) 검사

```bash
python C:\claude\mail100hanwon\_도구\schema-check.py C:\claude\내사이트
```

보는 것
- 페이지 성격(홈·원장소개·자주묻는질문·오시는길·칼럼)을 파일명으로 추정하고, **거기 맞는 표가 있는지**
- 표의 **필수 칸·권장 칸**이 찼는지 → 100점 만점 점수
- ★ **의료법 위험 칸**(후기·별점·상품·재고·판매자·가격)이 켜져 있는지 → **법위험** 등급으로 따로 표시
- ★ **표 안의 문장까지** 검사 — 특히 **FAQ 답변 본문**. 치료경험담("…한 사례가 있습니다")·효과 보장("부작용 없이 가능")·성공률·전문의약품 실명·인증 표방을 문장 패턴으로 잡는다
  (2026-08-08 추가. 그전에는 표 **종류**만 보고 답변 본문을 한 글자도 안 봐서, 실제 위반 문장을 전부 통과시켰다)
- 상호·주소·전화가 **페이지마다 같은지**
- 질문형 소제목이 3개 이상인데 FAQ 표가 없으면 → **"FAQ 기회"** 로 알려줌

## 3. `sitemap-gen.py` — sitemap.xml · robots.txt 만들기

```bash
python C:\claude\mail100hanwon\_도구\sitemap-gen.py C:\claude\내사이트 --url https://내주소.co.kr --dry
```

**항상 `--dry`(미리보기)로 먼저 보고**, 맞으면 `--dry` 를 빼고 다시 돌린다.

| 붙이는 말 | 뜻 |
|---|---|
| `--url https://…` | **필수.** 사이트 주소 |
| `--dry` | 만들지 말고 보여주기만 |
| `--no-robots` | sitemap만 |
| `--naver [코드]` | 네이버 소유확인 코드 → 넣을 한 줄을 알려준다 |

자동으로 들어가는 것
- **네이버 봇**: Yeti, NaverBot
- **검색엔진**: Googlebot, Bingbot, Daum 등
- **AI 봇 15종**: GPTBot, OAI-SearchBot, ChatGPT-User, PerplexityBot, ClaudeBot, Google-Extended, Applebot 등
- Sitemap 위치, Host

기존 파일은 `.bak` 으로 백업한 뒤 덮어쓴다.

## 결과를 읽을 때 주의할 것

1. **치명이 0이어야 배포한다.** 치명은 "검색에 아예 안 나오는" 상태다.
2. **법위험은 점수와 별개로 먼저 지운다.** → `05-의료법-충돌.md`
3. **B형(랜딩)에서 "내부링크 없음"·"글자 부족"이 안 뜨는 건 정상이다.** 원래 검색 유입이 목적이 아니다.
4. **페이지 성격 추정은 파일명 기준이다.** 파일명이 특이하면 "일반"으로 잡힌다. 그럴 땐 사람이 판단한다.
5. **이 도구들이 못 보는 것** — 실제 색인 여부 · 페이지 속도 · 배포된 뒤 상태. 그건 구글 서치콘솔과 `geo-check` 로 본다.
6. **점수가 높다 ≠ 검색에 잘 나온다.** 점수는 "AI가 읽을 수 있는 상태"까지만 재는 것이다. → `01-원리-쉽게.md §5`
